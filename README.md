# Rumoku
Lightweight and simple AI chat web UI

# 注意事項
* セキュアコーディングは期待しないでください。原則ローカルでホストして利用してください。
* セキュリティ上、拡張子「.db」ファイルをダウンロードできないようにWebサーバーの設定が必要です。
* インターネットに公開する場合、パスワード変更を必ず行ってください。
* デフォルトの基本認証のパスワードは適宜変更してください。デフォルトパスワード：admin ※DB初期化状態時のみ。
* 基本認証のユーザー名は、現在のディレクトリ名です。「/tmp/test/index.php」に配置した場合のユーザー名は「test」です。
* 基本認証のユーザー名は、ディレクトリ名が変わると可変することに気をつけてください。
* 配置ディレクトリ直下に書き込み権限が必要です。
* Open AI社のAPIキーが必要です。スクリプトの該当箇所を書き換えて下さい。
